# Kisi-kisi ASD

## 1. Stack & Queue
- Pelajari cara lacak posisi paling atas pakai penanda (stack).
- Pelajari cara lacak posisi depan & belakang pakai penanda (queue).
- Pelajari cara membuat stack & queue yang belum ada isi.
- Pelajari cara cek apakah isi-nya sudah penuh atau belum. 
- Pelajari variasi stack & queue (opsional buat additional insights).

## 2. Tree (Binary Tree)
- Pelajari cara susun data supaya bisa bercabang.
- Pelajari konsep komponen tree seperti node, root, leaf.
- Pelajari cara buat fungsi rekursif untuk periksa seluruh cabang pohon sampai selesai.
- Pelajari cara hitung jumlah leaf.
- Pelajari cara hitung height tree dari root sampai titik tujuan.
- Pelajari cara cek apakah pohon condong ke kiri/kanan saja.
- Pelajari cara hapus leaf paling kiri/kanan.

## 3. Hash Map
- Pelajari aritmetika modulo untuk penempatan data.
- Pelajari cara penanganan data collision (linear probing & bucket).

## 4. Heap Sort
- Pelajari keterkaitan antara binary tree dengan heap sort.
- Pelajari cara penyusunan data secara berurutan berdasarkan jenis heap.
- Pelajari cara tambah & hapus data.

## 5. Graph
- Pelajari konsep & komponen graph.
- Pelajari representasi graph dalam bentuk adjacency matrix & adjacency list.
